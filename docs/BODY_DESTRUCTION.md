# СИСТЕМА РАЗРУШЕНИЯ ТЕЛ — техдиз

Многослойная воксельная травма-система: базовый принцип Paint the Town Red
(слоистое тело, материалы, суставы, отрыв) плюс наш слой — органы, четыре типа
кровотечения, функциональные последствия, полевая медицина и протезы.

Написано под ЭТОТ движок: R3F + Rapier + Supabase Realtime, вокс-чувак из
`src/game/voxHumanoid.ts`, пул обломков `Debris`, инбокс-паттерн для кросс-модульной
связи, законы перфа из `GAME_BIBLE.md`. Все числа — стартовый тюнинг, не догма.

**Главный принцип: hybrid.** Настоящая воксельная симуляция там, где её видно
в упор (тело, по которому ты бьёшь), фейк там, где её не отличить (кровь,
дальние трупы, толпа ботов).

## 1. HIGH-LEVEL ARCHITECTURE

### 1.1 Ключевая находка нашего движка

Наш чувак — **не** миллион вокселей. При `BODY_VOXEL = 0.07` (половина текущего
`VOXEL = 0.14`) всё тело — **680 вокселей**:

| Часть | Сетка | Вокселей |
| --- | --- | --- |
| head | 6×6×6 | 216 |
| torso | 8×10×4 | 320 |
| arm ×2 | 2×8×2 | 32 → 64 |
| leg ×2 | 2×10×2 | 40 → 80 |
| **Итого** | | **680** |

680 вокселей = **85 байт** битовой маски «жив/разрушен» на всё тело. Это меняет
всё: нам не нужны damage-маски-приближения — мы можем позволить себе **честную
воксельную деструкцию** и всё равно реплицировать состояние целиком, если
понадобится. Дорого не хранение, дорого — **перестройка геометрии**, поэтому
ребилд мешей идёт по бюджету (§13).

### 1.2 Слои системы

```
CharacterTraumaState        ← один на бойца, единственный источник правды
├── BodyPart[6]             ← head, torso, armL, armR, legL, legR
│   ├── VoxelMask (Uint32Array) ← что осталось от части
│   ├── layerHp[5]          ← агрегат по слоям: skin/fat/muscle/bone/marrow
│   ├── JointState (к родителю)
│   └── LimbFunctionState   ← 0..1 работоспособность
├── Organ[10]               ← сердце/лёгкие/печень/… в контейнерах частей
├── BleedingState[]         ← активные источники (кап 6 на бойца)
├── vitals                  ← hp, blood, pain, shock, consciousness
└── seed                    ← детерминизм косметики
```

**Материал воксела не хранится** — он вычисляется: `materialAt(part, x, y, z)` —
чистая функция от позиции внутри части (§4.2). Ноль байт на материалы, полный
слоистый вид.

### 1.3 Граф тела

```
        head ──(neck)── torso
                          ├──(shoulderL)── armL ──(elbowL)── handL*
                          ├──(shoulderR)── armR ──(elbowR)── handR*
                          ├──(hipL)────── legL ──(kneeL)─── footL*
                          └──(hipR)────── legR ──(kneeR)─── footR*
```
`*` — суб-объёмы внутри той же части (не отдельные меши): отрыв по локтю/колену
режет маску части, а не создаёт новый узел графа. Так граф остаётся из 6 узлов,
но отрывов — 10 точек.

Отрыв родителя уносит всё поддерево (снёс плечо — рука с кистью улетает целиком).

### 1.4 Связь с рендером и физикой

- **Рендер**: у каждой части — `BufferGeometry`, собранная из живых вокселей.
  Ребилд только по изменению маски, через кэш `maskHash → geometry` (LRU 64).
- **Физика**: тело игрока — по-прежнему одна капсула (Rapier). Оторванные части
  — динамические тела из пула (кап 12 одновременно, §13). Рэгдолл — существующий
  пул `Ragdolls.tsx`.
- **Реакции**: `LimbFunctionState` → множители в движении/стрельбе. Никаких
  «анимаций-по-событию»: всё — из состояния, чтобы не рассинхронилось.

### 1.5 Границы репликации

| Что | Кто владеет | Как передаётся |
| --- | --- | --- |
| Урон, вычет HP | **жертва** (как сейчас) | `hit` broadcast → жертва применяет |
| Точка/тип/направление удара | стрелок | внутри `hit` (12 байт) |
| Воксельная маска | никто не шлёт | **реконструируется** детерминированно |
| Отрыв конечности | жертва | `trauma` broadcast (2 байта: partId + flags) |
| Кровотечения | жертва | флаги в `trauma`, партиклы — локально |
| Лужи, брызги, декали | **никто** | чисто клиентская косметика |
| Медицина | жертва / медик | `medact` broadcast |

Правило: **реплицируем причины, а не следствия.** Один `hit` порождает у всех
одинаковые воксельные карвы, потому что карв — чистая функция от `(part,
localPoint, radius, damageType, seed)`.

## 2. PTTR-STYLE BASELINE (как воспроизвести принцип, не копируя код)

### 2.1 Декомпозиция тела

6 частей → 16 суб-объёмов (для попаданий и отрывов, не для рендера):

| Часть | Суб-объёмы |
| --- | --- |
| head | skull, jaw, neck |
| torso | chest, abdomen, pelvis |
| arm | upperArm, forearm, hand |
| leg | thigh, shin, foot |

Суб-объём = диапазон по локальной Y внутри части. Определение попадания:
`subVolumeAt(part, localY)` — таблица порогов, ноль аллокаций.

### 2.2 Слои внутри конечности (радиальная модель)

Материал берётся из **глубины от поверхности** части:

```
depth 0        → SKIN      (оболочка, 1 воксель)
depth 1        → FAT       (только torso/thigh; на предплечье пропускается)
depth 1..2     → MUSCLE
core column    → BONE      (цилиндр по оси части, радиус 1)
core of bone   → MARROW    (только толстые кости: бедро, плечо, таз)
```

Голова — спецкейс: `SKIN → SKULL(bone) → BRAIN`. Мозг — сфера радиусом 2 в
центре черепа.

Торс — спецкейс: под мышцами не кость, а **органная полость** с рёбрами
(BONE-решётка спереди/сзади, промежутки между рёбрами — прямой путь к органам).

### 2.3 Типы урона

| Тип | Что делает | Профиль карва |
| --- | --- | --- |
| `sharp` (клинок) | **срез плоскостью**, малый разброс | плоскость + толщина 1 воксель, длина по силе замаха |
| `blunt` (дубина) | давит: дробит кость, кожу не режет | сфера, но SKIN получает ×0.3, BONE ×2.2 → перелом без раны |
| `pierce` (пуля, копьё) | канал | цилиндр r=1..2 по направлению, глубина по пробитию |
| `explosive` | всё сразу + импульс | сфера r=4..9 + отрыв всех суставов в радиусе |
| `laser/energy` | прожиг, прижигает | цилиндр r=1, кровотечение **не** создаётся (каутеризация) |

### 2.4 Правила разрушения вокселя

```
voxelHp = MATERIAL[mat].hp
effective = damage × MATERIAL[mat].resist[damageType] × falloff(dist)
voxel.hp -= effective
если voxel.hp <= 0 → бит в маске гаснет, в Debris улетает кусок цвета материала
```
HP вокселей **не хранится**: одно попадание либо гасит воксель, либо нет
(`effective >= MATERIAL[mat].hp`). Частичные повреждения живут на уровне
`layerHp` части — это агрегат, 5 чисел, а не 680.

### 2.5 Slice planes (клинки)

Замах саблей = плоскость `(origin, normal)` + глубина. Гасим все воксели части,
чей центр лежит в слэбе толщиной 1.5 вокселя. Если плоскость перерезала **ось
кости** — сустав ниже среза мгновенно фейлится (чистый отруб). Это даёт
«clean slice» без отдельной системы.

### 2.6 Перф-дружелюбность baseline

- Маска — `Uint32Array(11)` на часть (max 320 бит), карв — битовые операции
- Ребилд геометрии — только для частей, чья маска изменилась, ≤2 частей/кадр
- Дальние бойцы (>45 юнитов) не карвятся вообще: только `limbMask` + кровь-импостор
- Боты орды (до 64 штук) используют **упрощённый профиль**: без вокселей, только
  6 частей × 4 состояния (целая / повреждена / раздроблена / оторвана)

## 3. DATA MODEL

Всё — плоские структуры, `Int8Array`/`Uint32Array` где можно. Ноль классов
в горячем пути.

### 3.1 `VoxelMaterialDefinition`

```ts
interface VoxelMaterialDefinition {
  id: MaterialId;              // 0..8, индекс в MATERIALS
  label: string;               // 'КОЖА' — для отладки и HUD ран
  hp: number;                  // порог разрушения одного вокселя
  density: number;             // 0..1, влияет на импульс обломка
  resist: {                    // множитель ВХОДЯЩЕГО урона (меньше = крепче)

    blunt: number;
    pierce: number;
    explosive: number;

  color: string;               // цвет обломка в Debris
  sfx: 'wet' | 'crack' | 'tear' | 'thud' | 'sizzle';
  exposesBelow: boolean;       // разрушение открывает вид на слой ниже
}
```

### 4.1 Таблица тюнинга (стартовые числа)

| Материал | hp | density | sharp | blunt | pierce | expl | fracture | blood | sfx |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| SKIN | 6 | 0.25 | 1.6 | 0.4 | 1.3 | 1.2 | — | 0.15 | tear |
| FAT | 8 | 0.20 | 1.4 | 0.7 | 1.1 | 1.2 | — | 0.20 | wet |
| MUSCLE | 18 | 0.45 | 1.3 | 0.9 | 1.0 | 1.3 | 40 | 0.55 | wet |
| TENDON | 26 | 0.55 | 1.8 | 0.5 | 0.7 | 1.0 | 30 | 0.10 | tear |
| BONE | 60 | 0.85 | 0.5 | 1.8 | 0.6 | 1.4 | 55 | 0.05 | crack |
| MARROW | 12 | 0.30 | 1.0 | 1.0 | 1.0 | 1.3 | — | 0.75 | wet |
| BRAIN | 10 | 0.20 | 1.5 | 1.6 | 1.5 | 1.8 | — | 0.60 | wet |
| ORGAN | 14 | 0.35 | 1.5 | 1.3 | 1.4 | 1.6 | — | 0.90 | wet |
| ARMOR | 90 | 1.00 | 0.25 | 0.8 | 0.45 | 0.9 | 70 | 0.00 | thud |

Читается так: **клинок** отлично режет кожу/мышцу/сухожилие и плохо берёт кость;
**дубина** почти не рвёт кожу, но дробит кость (перелом без открытой раны —
внутреннее кровотечение); **пуля** ровно проходит мягкие ткани и вязнет в кости.

### 4.2 `materialAt` — материал без хранения

```
materialAt(part, x, y, z):
  d = depthFromSurface(part.grid, x, y, z)   // манхэттен до границы сетки
  profile = part.layerProfile

  если profile == 'head':
      если insideSphere(центр черепа, r=2)  → BRAIN
      если d == 0                            → SKIN
      иначе                                  → BONE   // череп
  если profile == 'torso':
      если d == 0                            → SKIN
      если d == 1                            → FAT
      если organAt(x,y,z) != -1              → ORGAN
      если ribAt(x,y,z)                      → BONE
      иначе                                  → MUSCLE
  профиль 'limb':
      если d == 0                            → SKIN
      если onBoneAxis(x, z, r=1)             → (толстая кость и центр) ? MARROW : BONE
      если nearJointBand(y)                  → TENDON
      иначе                                  → MUSCLE
```
Одна функция, ноль памяти, полный слоистый вид. Броня/одежда — **отдельный
оверлей-слой** `d == -1`: виртуальный слой перед SKIN, живёт как одно число
`armorHp` на суб-объём (не воксель), чтобы не раздувать сетку.

### 4.3 VFX/SFX по слоям

- SKIN/FAT — брызги мелкие, звук `tear`, декаль-порез
- MUSCLE — фонтан обломков цвета `#c9184a`, `wet`, «мясной» удар
- BONE — белые щепки, `crack`, при переломе — характерный хруст и **питч вниз**
- BRAIN — розово-серое, `wet` + эхо-реверб + мгновенный кадр-фриз 60 мс на убийце
- ORGAN — тёмное, `wet`, при разрыве — низкочастотный удар в сабе

## 5. DAMAGE PIPELINE

Полный путь от выстрела до последствий. Номера — этапы, они же порядок в коде.

```
1  HIT DETECTION
   Рейкаст/меш-оверлап (как сейчас, Player.tsx) → hitObject + worldPoint + normal
   Идём вверх по родителям до userData.isEnemy && isPlayer → корневая группа

2  BODY PART RESOLUTION
   localPoint = root.worldToLocal(worldPoint)         // снимает поворот и МАСШТАБ (L/K)
   part       = partAt(localPoint)                     // 6 узлов
   sub        = subVolumeAt(part, localPoint.y)        // 16 суб-объёмов
   voxel      = voxelIndexAt(part, localPoint)

3  IMPACT ANGLE
   incidence = dot(shotDir, surfaceNormal)
   grazing   = incidence > -0.35   → рикошет: урон ×0.4, карв поверхностный

4  DAMAGE TYPE
   из спецификации оружия: sharp | blunt | pierce | explosive | energy
   Меле-замах даёт ещё swingSpeed → множитель проникновения

5  PENETRATION / SHEAR / CRUSH
   pierce: маршируем по лучу вглубь, на каждом вокселе вычитаем MATERIAL.hp
           из «бюджета пробития»; кончился — застряли (пуля в кости)
   sharp:  строим slice-плоскость, идём по слэбу
   blunt:  сфера, но SKIN получает ×0.4 → кожа цела, кость внутри трещит
   expl:   сфера r по мощности + импульс в Rapier

6  VOXEL REMOVAL
   for each воксель в профиле карва:
       mat = materialAt(...)
       eff = dmg × mat.resist[type] × falloff(dist)
       если eff >= mat.hp → гасим бит, копим bloodYield, шлём обломок в Debris
       иначе → layerHp[part][mat] -= eff   (частичный урон копится на слое)

7  ORGAN EXPOSURE
   если карв дошёл до слоя ORGAN/BRAIN → organHp[id] -= eff
   если organ.vital и hp <= 0 → planDeath(organ.deathDelayMs)
   если organ.canSpill и integrity(torso) < 0.4 → spillOrgan() (§7.4)

8  BLEEDING
   bleedType = worstOf(разрушенные слои)     // ARTERY > ORGAN > MUSCLE > SKIN
   если тип energy → каутеризация, кровотечения НЕТ
   spawnBleedingState(wound, type, rate)

9  JOINT FAILURE
   для сустава между part и родителем: evaluateJointFailure() (§6)

10 LIMB FUNCTION RECALC
   recomputeCharacterFunction() → множители движения/стрельбы (§9)

11 REACTION
   stagger/scream/limp по severity; у AI — смена поведения (§11)

12 PHYSICS & VFX
   обломки (пул), брызги (пул), декаль на пол, шок-кольцо при взрыве
   оторванная часть → динамическое тело из пула (кап 12)

13 NETWORK
   жертва применила урон → шлёт `trauma` только при СМЕНЕ дискретного состояния
   (отрыв / новый тип кровотечения / смена FSM-стейта). Всё остальное клиенты
   реконструируют из уже полученного `hit`.
```

## 6. DISMEMBERMENT RULES

### 6.1 Формула отказа сустава

```
tissueRatio  = 1 − (живые воксели в поясе сустава / всего в поясе)
jointDamage  = накопленный урон по суставу / joint.hp
typeBonus    = sharp ? joint.sharpBonus : blunt ? joint.bluntBonus : 1.0

severChance  = clamp01(
                 (tissueRatio − joint.tissueRatioToFail) × 2.0
               + jointDamage × 1.2
               ) × typeBonus

ОТРЫВ, если: tissueRatio >= joint.tissueRatioToFail  ИЛИ  jointDamage >= 1
ЧАСТИЧНЫЙ (hanging), если severChance ∈ [0.55, 1.0)
```
Никакого рандома в решении об отрыве — только в косметике. Это обязательное
условие детерминизма для мультиплеера.

### 6.2 Пороги по точкам (стартовый тюнинг)

| Сустав | joint.hp | tissueRatioToFail | sharpBonus | killIfSevered |
| --- | --- | --- | --- | --- |
| neck (шея) | 55 | 0.65 | 3.0 | **да** |
| shoulder | 70 | 0.72 | 2.5 | нет |
| elbow | 45 | 0.60 | 2.8 | нет |
| wrist (кисть) | 28 | 0.50 | 3.2 | нет |
| hip | 95 | 0.80 | 2.0 | нет |
| knee | 60 | 0.65 | 2.6 | нет |
| ankle (стопа) | 32 | 0.52 | 3.0 | нет |

Читается: **кисть отлетает легче всего** (28 hp, 50 % ткани) — один хороший удар
клинком. **Бедро — почти не оторвать** пулями, нужен взрыв или долгая рубка.

### 6.3 Что рвётся от чего

- **Кисть**: один `sharp` ≥ 30 урона по суб-объёму `hand`, либо `blunt` ≥ 55
  (раздробить), либо 3 попадания `pierce`
- **Рука (по плечу)**: `sharp` ≥ 70, взрыв в упор, либо 65 % ткани плеча выбито
- **Нога (по бедру)**: практически только `explosive` или клинок с двух замахов
- **Голова**: `sharp` ≥ 60 по шее = чистое обезглавливание → **мгновенная смерть**;
  `blunt` голову не отрывает — он **проламывает череп** и убивает через BRAIN
- **Neck kill**: отдельная ветка — если `joint.killIfSevered`, ставим
  `state = DEAD` мгновенно, минуя агонию. Это наша замена «brain instant kill»
  из PTTR, работающая с двух сторон (мозг ИЛИ шея)

### 6.4 Partial sever — «висит на лоскуте»

`hanging = true` даёт:
- работоспособность конечности **0.15** (рука не держит оружие, нога подламывается)
- **артериальное** кровотечение с ×1.4 к темпу
- визуально: часть смещена по суставу на 0.4 вокселя, болтается синусом
  `sin(t·6) × 0.25` рад, соединена «жгутом» из 3 вокселей MUSCLE
- **добить**: любой следующий урон ≥ 12 по этой части = полный отрыв
- **пришить**: `TryReattach` возможен ТОЛЬКО в состоянии hanging (§10)

### 6.5 Оторванная часть и труп

- Оторванная часть → динамическое тело из пула (кап 12, TTL 25 с, потом растворяется
  в вокс-гор через существующий `makeGore`)
- Наследует импульс выстрела × `joint.detachImpulse` × `1/massKg`
- Оставляет **след крови** первые 3 с полёта/качения
- Труп: сохраняем маску вокселей, но переводим рендер в **статичную запечённую
  геометрию** (одна перестройка, дальше ноль), физику — в один коллайдер-капсулу
- Кап трупов: 8, дальше — самый старый растворяется

### 7.3 Как связаны с частями

Орган живёт в AABB внутри `torso`/`head`. Попадание достаёт орган, только если
карв дошёл до слоя `ORGAN` (то есть пробил кожу+жир+мышцу или прошёл **между
рёбер**). Рёберная решётка — реальная геометрия в `materialAt`, поэтому
«попал между рёбер» — эмерджентное свойство, а не спецкейс.

Отрыв `torso` невозможен (это корень) — но при `integrity(torso) < 0.15` персонаж
переходит в `DEAD` вне зависимости от органов.

### 7.4 Выпадение органов (`spill`)

Триггер: `INTESTINES.hp < 0.5` И `integrity(abdomen) < 0.4` И тип урона
`sharp|explosive`.

Реализация — **дёшево**: один динамический «мешок» (3 капсулы-звена на джойнтах
Rapier), тянется за персонажем, пока он двигается, оставляет след. При беге —
рывок и `pain +0.5`. Кап: 1 на бойца, 3 на сцену.

### 7.5 Визуализация без убийства перфа

- Органы **не рендерятся**, пока не открыты: они внутри и невидимы
- При открытии полости — рендерим ОДНУ merged-геометрию «внутренности»
  (8 боксов, общий материал) вместо 10 отдельных органов
- Повреждённый орган темнеет через `instanceColor`, не через новый материал
- Дальше 30 юнитов — органы не рендерятся вообще

## 8. BLOOD SIMULATION

### 8.1 Четыре типа

| Тип | Триггер | Темп (мл/с) | Профиль |
| --- | --- | --- | --- |
| **ARTERIAL** | артерия, почка, селезёнка, сердце, отрыв конечности | 90–400 | **Пульсирующий фонтан**: всплеск на каждый удар сердца (1.1 Гц, ускоряется с шоком), дальность струи `1.8 м × pressure`, ослабевает по мере падения давления |
| **VENOUS** | мышца, печень, лёгкое, кишки | 25–130 | Ровный поток вниз по телу, стекает, копит лужу |
| **CAPILLARY** | кожа, жир, царапины | 3–12 | Просачивание, окрашивает воксели вокруг раны, само останавливается за 20 с |
| **INTERNAL** | тупой урон, перелом без раны, мозг | 15–120 | **Наружу не видно.** Копит `internalLoss`, кожа синеет, растёт `shock`. Лечится только хирургией/магией |

### 8.2 Формула давления

```
pressure   = clamp01(bloodVolume / 5000) ^ 0.7
arterialRate = baseRate × pressure × (1 + shock × 0.3)
totalLoss/s = Σ активных bleeds
```
Кровь падает → давление падает → артериальный фонтан слабеет → это **само по себе
драматургия**: первый фонтан бьёт через полкомнаты, последний еле капает.

### 8.3 Пороги кровопотери

| Осталось крови | Состояние |
| --- | --- |
| 5000–4200 | норма |
| 4200–3400 | бледность, `stamina` −20 % |
| 3400–2600 | тахикардия, тремор прицела, пульс в ушах |
| 2600–1800 | **туннельное зрение**, ч/б по краям, шатание |
| 1800–1200 | `UNCONSCIOUS` — падение, только ползти |
| < 1200 | `DEAD` |

### 8.4 Кровь и косметика

- Партиклы — **существующий пул `Debris`**, никаких новых рендер-путей
- Лужи — импостор-квады на полу, кап 24, сливаются по расстоянию < 0.5
- **След при ползании/беге** — квады с интервалом по пройденному пути (0.6 юнита),
  затухают за 30 с; кап 40 на сцену
- Экран: своя кровь брызгает на «объектив» (SDF-капли, затухают за 6 с)
- Звук: артериальный — ритмичный «чпок» в такт пульсу; венозный — фон капели
- **Вся кровь — чисто клиентская.** Ноль байт в сеть

### 8.5 Геймплейное следствие

Лужи **скользкие**: трение −35 % → в CS-карте это реальный тактический слой
(влетел в комнату на бхопе по луже — унесло на стену).

## 9. FUNCTIONAL CONSEQUENCES

### 9.1 Формула работоспособности конечности

```
function(limb) =
    detached                     → 0
    hanging                      → 0.15
    prosthetic                   → prosthetic.functionRestored (0.55…0.9)
    иначе:
        base = integrity                     // доля живой ткани 0..1
        если !boneIntact  → base ×= 0.35     // перелом
        если !jointIntact → base ×= 0.5
        base ×= (1 − pain × 0.4)
        → clamp(base, 0, 1)
```

### 9.2 Конечный автомат состояния бойца

```
        ┌──────────┐  урон
        │  HEALTHY │───────────┐
        └────┬─────┘           ▼
             │           ┌──────────┐  function(leg) < 0.35
             │           │ WOUNDED  │──────────────┐
             │ лечение   └────┬─────┘              ▼
             └────────────────┤              ┌──────────┐
                              │ shock > 0.7  │ CRAWLING │
                              ▼              └────┬─────┘
                        ┌──────────┐              │ кровь < 1800
                        │  SHOCK   │              ▼
                        └────┬─────┘        ┌──────────────┐
                             │              │ UNCONSCIOUS  │
                             └─────────────▶└──────┬───────┘
                                                   │ кровь < 1200
                                                   ▼ или vital-орган
                                             ┌──────────┐
                                             │   DEAD   │
                                             └──────────┘
```
Переходы **только вниз**, кроме лечения (`WOUNDED → HEALTHY`) и реанимации
(`UNCONSCIOUS → CRAWLING` при остановленном кровотечении + аптечка).

### 9.3 Числовые последствия

**Потеря ноги**
```
speed      ×= 0.5 при одной, 0.0 при двух → CRAWLING (0.9 юнита/с)
jump        = запрещён при function(leg) < 0.3
камера      = высота глаз 0.42 (одна) / 0.18 (обе)
bleed       = ARTERIAL 180 мл/с (бедренная артерия)
падение     = мгновенный stagger 1.2 с при отрыве
```

**Потеря руки**
```
двуручное оружие → недоступно, автопереход на одноручный fallback
перезарядка     ×= 2.2
разброс         += 0.055 рад постоянно
отдача          ×= 1.6 (нечем удержать)
крюк-кошка      → недоступен (нечем ловить)
магия           → нестабильна: 25 % шанс осечки с откатом урона в себя
две руки        → оружие выпадает физическим телом, остаётся только удар головой
```

**Травма живота**
```
stamina регенерация → 0
рывок/спринт        → каждый рывок +8 % к риску spill
если spill активен  → speed ×0.75, pain +0.5, крик при каждом рывке
```

**Травма груди**
```
breath        ↓ → стамина не восстанавливается
aim sway      += 0.012 рад/с × повреждение лёгких
звук          = хрип, слышен врагам в радиусе 12 юнитов (тактическое следствие!)
```

**Травма головы**
```
tunnel vision  = виньетка × (1 − 0.6 × повреждение)
confusion      = инверсия горизонтальной оси мыши на 0.4 с при severity > 0.6
череп пробит   → 3 с до смерти, если не каутеризовать
мозг разрушен  → DEAD мгновенно
```

**Шок**
```
shock += (loss/s / 400) × dt + pain × 0.15 × dt
shock -= 0.04 × dt при остановленном кровотечении
при shock > 0.7 → SHOCK: цвет вымывается, звук глохнет (лоупасс 700 Гц),
                   управление вязнет (лерп ввода 0.4)
```

## 12. MULTIPLAYER REPLICATION

### 12.1 Что летит по сети

| Событие | Размер | Частота | Кто шлёт |
| --- | --- | --- | --- |
| `hit` (есть сейчас) + `part`,`sub`,`lp`(3×int8),`type`,`seed` | ~14 байт | на выстрел | стрелок |
| `trauma` (дискретная смена) | ~8 байт | на отрыв / новый bleed / смену FSM | жертва |
| `medact` | ~6 байт | на действие | лечащий |
| `corpse` (финальная маска) | ~90 байт | 1 раз на смерть | жертва |

Всё. **Воксельные маски, кровь, обломки, лужи, декали, крики — не летят.**

### 12.2 Детерминизм

Карв — чистая функция:
```
carve(mask, part, localPoint, type, damage, seed) → mask'
```
Никаких `Math.random()` внутри. Косметика (разлёт обломков, форма брызг) —
`mulberry32(seed ^ woundId)`, seed приходит в `hit`. Итог: у обоих игроков
одинаковые дырки в теле, но разлёт капель может отличаться — и это разрешено.

### 12.3 LOD гора

| Дистанция | Что считаем |
| --- | --- |
| < 15 юнитов | полный воксельный карв + органы + все эмиттеры |
| 15–45 | карв без органов, 1 эмиттер крови, обломков ×0.4 |
| > 45 | только `limbMask` (что оторвано) + импостор-брызг |
| боты орды | упрощённый профиль: 6 частей × 4 состояния, без вокселей |

### 12.4 Оторванные части

Реплицируется **факт** отрыва (partId + импульс, 8 байт). Само тело части —
локальный физический объект у каждого клиента. Расхождение позиции обломка
никого не волнует: он ни на что не влияет. **Правило: если объект не влияет на
исход боя — он не реплицируется.**

### 12.5 Анти-десинк

1. Урон применяет **только жертва** (уже так работает) — нет двойного учёта
2. Дискретные состояния (отрыв, смерть, FSM) — авторитет жертвы, остальные
   принимают без спора
3. `version` в `CharacterTraumaState`: при расхождении клиент запрашивает
   полный снапшот (90 байт) — дёшево и редко
4. Поздний джойн: получаешь снапшоты трупов и живых одним пакетом
5. **Никогда** не выводим геймплейное решение из локальной косметики

## 13. PERFORMANCE STRATEGY

### 13.1 Бюджеты на кадр

| Ресурс | Кап |
| --- | --- |
| Перестроек геометрии частей | **2 / кадр** (очередь, приоритет по дистанции) |
| Активных эмиттеров крови | **6 на бойца, 18 на сцену** |
| Оторванных динамических тел | **12** |
| Трупов с сохранённой маской | **8** |
| Луж крови (импостор-квады) | **24** |
| Кровавых следов | **40** |
| Партиклов гора в кадре | существующий пул `Debris`, без расширения |
| Органных мешков (spill) | **3** |

### 13.2 Когда честные воксели, когда маска

- **Честный карв**: игроки (2–8 штук) и ближние боты (< 15 юнитов)
- **Маска состояний**: орда (до 64 ботов) — 6 частей × 2 бита = 12 бит на бота
- **Ничего**: дальше 45 юнитов — только `limbMask` и цвет

### 13.3 Приёмы

- Геометрия части кэшируется по хешу маски: у ботов масок мало → почти всегда
  попадание в кэш, ноль ребилдов
- Труп «запекается» один раз, дальше статичен
- Кровь на полу — **не декали на меши**, а квады в одном `InstancedMesh`
- Эмиттеры затухают: через 8 с артериальный переходит в венозный визуал (дешевле)
- Все новые материалы — **общие модульные константы**, как во всём проекте
- `raycast = NO_RAYCAST` на всём, что чисто визуально (кровь, обломки, органы)

## 14. MVP ROADMAP

### Фаза 1 — Baseline PTTR (фундамент)
**Фичи:** воксельные маски на 6 частей · `materialAt` со слоями skin/fat/muscle/
bone · типы урона sharp/blunt/pierce · карв и разрушение вокселей · суставы и
отрыв · чистый срез клинком · шея = мгновенная смерть · перестройка геометрии
по маске · базовые обломки и звук слоёв.
**Зависимости:** текущий `limbZoneAt` (уже есть), `Debris`, `VoxDude`.
**Риски:** ребилд геометрии в кадре → лаг. **Митигация:** очередь 2/кадр + кэш.
**Что фейкать:** органы, типы крови, лечение — пока нет.

### Фаза 2 — Расширенный отрыв и ползание
**Фичи:** 10 точек отрыва (кисть/локоть/плечо/стопа/колено/бедро/шея) · `hanging`
· оторванные части как физические тела · ползание · деградация боя без руки ·
позы защиты раненой конечности · крики и stagger · реакции AI.
**Зависимости:** Фаза 1 + существующие `crippledUntil`/`armsUntil` (переезжают
в новую модель).
**Риски:** ползание ломает бхоп-фил. **Митигация:** ползание — отдельный режим
движения, не модификатор.
**Что фейкать:** протезы, шину.

### Фаза 3 — Органы и кровь
**Фичи:** 10 органов · рёберная решётка · 4 типа кровотечения · давление и
кровопотеря · пороги сознания · выпадение кишок · лужи, следы, скользкость ·
экранные эффекты (туннель, пелена, лоупасс).
**Зависимости:** Фазы 1–2.
**Риски:** кровь съедает fps. **Митигация:** жёсткие капы §13, импосторы.
**Что фейкать:** внутреннее кровотечение — только число + цвет кожи, без симуляции.

### Фаза 4 — Медицина, протезы, мультиплеер-полировка
**Фичи:** бинт/жгут/шов/шина/прижигание · пришивание за 25 с · временные и
полные протезы · оттаскивание союзника · дельта-репликация травмы · LOD гора ·
снапшоты для поздних заходов.
**Зависимости:** Фазы 1–3.
**Риски:** десинк лечения. **Митигация:** авторитет жертвы + `version`.
**Что фейкать:** гангрену от жгута — таймер, не симуляция.

## 15. PSEUDOCODE

```
ApplyHit(target, worldPoint, dir, normal, weapon):
    lp    = target.root.worldToLocal(worldPoint)     // снимает поворот и масштаб
    part  = partAt(lp)
    sub   = subVolumeAt(part, lp.y)
    type  = weapon.damageType
    dmg   = weapon.damage × angleFalloff(dot(dir, normal))

    wound = { part, sub, localPoint: lp, type, severity: dmg / 100 }

    carved = ResolveVoxelDamage(target, part, lp, dir, dmg, type, weapon.seed)

    если carved.reachedOrgan >= 0:
        DamageOrgan(target, carved.reachedOrgan, dmg)

    wound.depthReached = carved.deepestMaterial
    SpawnBleedingState(target, wound, carved)

    для каждого joint, касающегося part:
        если EvaluateJointFailure(target, joint, type, dmg):
            TryDetachLimb(target, joint, dir × weapon.impulse)

    RecomputeCharacterFunction(target)
    EmitReaction(target, wound)
    если target.isLocal: SerializeTraumaForNetwork(target)


ResolveVoxelDamage(t, part, lp, dir, dmg, type, seed):
    профиль = carveProfile(type, dmg)      // sphere | plane-slab | cylinder
    бюджет  = penetrationBudget(type, dmg)
    deepest = SKIN; organHit = -1; bloodYield = 0

    для каждого voxel в профиле (по порядку глубины вдоль dir):
        если !alive(t.masks[part], voxel): continue
        mat = materialAt(part, voxel)
        eff = dmg × MATERIAL[mat].resist[type] × falloff(voxel, lp)

        если eff >= MATERIAL[mat].hp:
            clearBit(t.masks[part], voxel)
            bloodYield += MATERIAL[mat].bloodYield
            SpawnDebrisChunk(voxel, MATERIAL[mat].color, dir, seed)
            бюджет -= MATERIAL[mat].hp
            если mat > deepest: deepest = mat
            если mat == ORGAN или mat == BRAIN: organHit = organAt(part, voxel)
        иначе:
            t.layerHp[part][mat] -= eff
            если mat == BONE и t.layerHp[part][BONE] <= 0:
                t.limbs[part].boneIntact = false
                PlaySfx('crack'); SpawnBleeding(INTERNAL)

        если бюджет <= 0: break            // пуля застряла

    QueueGeometryRebuild(t, part)          // очередь, макс 2/кадр
    вернуть { deepestMaterial: deepest, reachedOrgan: organHit, bloodYield }


EvaluateJointFailure(t, joint, type, dmg):
    пояс        = voxelBandAt(joint)
    tissueRatio = 1 − aliveCount(t.masks, пояс) / totalCount(пояс)
    t.jointDmg[joint] += dmg × typeBonus(joint, type)

    если tissueRatio >= joint.tissueRatioToFail: вернуть ПОЛНЫЙ
    если t.jointDmg[joint] >= joint.hp:          вернуть ПОЛНЫЙ
    если tissueRatio >= joint.tissueRatioToFail × 0.8: вернуть ЧАСТИЧНЫЙ
    вернуть НЕТ


TryDetachLimb(t, joint, impulse):
    если исход == ЧАСТИЧНЫЙ:
        t.limbs[joint.partB].hanging = true
        SpawnBleedingState(t, joint, ARTERIAL, ×1.4)
        вернуть

    t.limbs[joint.partB].detached = true
    для каждого потомка partB: detached = true          // поддерево улетает
    clearAllBits(t.masks[joint.partB])

    если freeDetachedBodies() > 0:
        SpawnDetachedBody(partB, impulse × joint.detachImpulse / massKg)
    иначе:
        SpawnGoreBurst(partB)                            // кап исчерпан — просто гор

    SpawnBleedingState(t, joint, ARTERIAL, base = 180)
    если joint.killIfSevered: t.state = DEAD; вернуть
    RecomputeCharacterFunction(t)
    Broadcast('trauma', { part: joint.partB, flags: DETACHED })


SpawnBleedingState(t, wound, carved):
    если wound.type == ENERGY: вернуть                    // прижгло
    тип = worstBleedOf(carved.deepestMaterial, carved.reachedOrgan)
    темп = BLEED_BASE[тип] × (1 + carved.bloodYield)

    если t.bleeds.length >= 6:
        заменить самый слабый
    t.bleeds.push({ тип, темп, начало: now, эмиттер: acquireEmitter() })


RecomputeCharacterFunction(t):
    для каждой limb:
        limb.integrity = aliveCount(t.masks[limb]) / totalCount(limb)
        limb.function  = formula§9.1(limb, t.pain)

    legs = (function(legL) + function(legR)) / 2
    arms = (function(armL) + function(armR)) / 2

    t.mobility = legs < 0.15 ? 0 : legs < 0.35 ? 0.5 : legs
    t.canJump  = legs >= 0.3
    t.aimSway  = 0.004 + (1 − arms) × 0.05 + lungDamage × 0.012
    t.reload   = 1 / max(0.25, arms)
    t.state    = fsmTransition(t)                        // §9.2


ApplyMedicalAction(t, action, targetWound):
    если !action.preconditions(t, targetWound): вернуть FAIL
    если прервано во время action.timeMs:      вернуть INTERRUPTED

    consumeResource(action.cost)
    для каждого эффекта в action.fixes:
        применить (остановить bleed / boneIntact = true / reattach)
    для каждого штрафа в action.tradeoffs:
        применить (function ×0.4, таймер гангрены, pain += …)

    RecomputeCharacterFunction(t)
    Broadcast('medact', { action: action.id, wound: targetWound.id })


SerializeTraumaForNetwork(t):
    // только дискретное — 8 байт
    p = 0
    для i в 0..5: p |= (t.limbs[i].detached ? 1 : 0) << i
    для i в 0..5: p |= (t.limbs[i].hanging  ? 1 : 0) << (6 + i)
    вернуть {
        limbFlags: p,                 // 12 бит
        bleedMask: bleedTypeMask(t),  // 4 бита
        state:     t.state,           // 3 бита
        version:   ++t.version,
    }
```

## 16. FINAL DELIVERABLE

### 16.1 Технический конспект

Тело — 6 частей и 680 вокселей; материал вокселя не хранится, а **вычисляется**
от глубины (`materialAt`), поэтому слоистое тело стоит ноль памяти. Урон — карв
маски по профилю (сфера / плоскость-срез / цилиндр-канал) с бюджетом пробития.
Отрыв — детерминированная формула «разрушено ткани вокруг сустава + накопленный
урон по суставу», без рандома. Органы — AABB внутри торса и черепа, достаются
только через пробитую полость или между рёбер. Кровь — четыре типа с моделью
давления, вся косметика клиентская. В сеть летят **причины** (попадание, 14 байт)
и **дискретные состояния** (отрыв, кровотечение, FSM, 8 байт), всё остальное
реконструируется локально. Перф держится жёсткими капами и LOD: честные воксели
только вблизи, орда — на 12 битах.

### 16.4 Топ-10 граблей

1. **Ребилд геометрии в кадре попадания** — очередь и кэш по хешу маски, иначе
   каждый выстрел = микрофриз
2. **Рандом внутри карва** — мгновенный десинк; весь рандом только в косметике
   и только от переданного `seed`
3. **Отрыв, решаемый на стороне стрелка** — двойной учёт; решает жертва
4. **`worldToLocal` без учёта масштаба** — у нас есть рост `L`/`K`, попадания
   уедут; всегда через матрицу группы, никогда вручную
5. **Кровь как декали на меши** — убьёт fps; только импостор-квады в инстансе
6. **Оторванные части без капа** — Rapier ляжет; пул на 12 и деградация в гор
7. **Ползание как модификатор скорости** — сломает бхоп-фил; это отдельный режим
   движения со своим блоком физики
8. **Лечение, которое чинит всё** — убивает драматургию; магия не отращивает
   потерянное
9. **Органы как отдельные меши** — 10 драв-коллов на бойца; одна merged-геометрия
   «внутренности», появляется только при вскрытой полости
10. **Порог отрыва, завязанный только на урон** — получится «взорвал руку из
    пистолета»; обязательна связка «разрушенная ткань вокруг сустава + урон
    по суставу»
