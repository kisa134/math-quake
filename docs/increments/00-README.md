# Math Quake — Production Bible (increments)

Психоделический мультиплеерный аренный воксель-шутер. Мир: внутри финансовых графиков / матрицы / космоса. Ядро: лучшее движение из CS (распрыжка/bhop), Quake (air-strafe), Chained Together (бесконечный прыжок вверх). Сочная физика, воксельное разрушение, гор.

## Метод (закреплён с владельцем)
- **Дизайн — широко и заранее:** детальные AAA-спеки на каждый инкремент (в этой папке), с конкретными числами, структурами данных и привязкой к реальному коду. Специализированные агенты пишут ТОЛЬКО спеки (документы).
- **Код — узко и по очереди:** реализую я, ОДИН инкремент за раз, каждый — законченный сочный playable-срез (senior first pass, не заглушка). Владелец играет и подтверждает до перехода к следующему.
- **Визуал вижу не я:** встроенный браузер держит вкладку `hidden` → rAF стоит → скриншот пуст. Плейтест-глаза = владелец; я — код + консоль/сеть + числа.

## Стек (веб-нативный)
React 19 · @react-three/fiber · @react-three/drei · **@react-three/rapier** (физика) · three 0.185 · zustand · socket.io · Vite/Express (`npm run dev` → :3000). Мультиплеер-сервер = `server.ts` (комнаты, join/update/shoot/hit/death/score).

## Ограничения / принципы
- **Сеть-first:** это онлайн-игра. НИКАКОГО замедления времени / hit-stop / тайм-скейла (владелец отверг тайм-дисторшн). Джус — без искажения времени: шейк, вспышки, партиклы, звук, отдача.
- Держать 60 fps: пулы объектов, инстансинг, лимиты дебриса, отсутствие аллокаций в useFrame.
- Мультиплеер-детерминизм: разрушение/дебрис косметичны локально; авторитет по HP/смерти — на сервере.
