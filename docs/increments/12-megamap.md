# 12 — MEGA-MAP: «THE EXCHANGE» (многоуровневая вертикальная арена)

> **Инкремент 12.** Карта — наконец «сделанная правильно»: одна большая, максимально
> продуманная, **многоуровневая** арена внутри психоделического неон-финанс-космоса.
> Хорошая **и по вертикали, и по горизонтали**: разные высотные ярусы боя, разрушаемое
> укрытие, платформинг, читаемость в психоделии. Референсы (переведены в НАШ сеттинг, не
> буквально): **Elden Ring** — взаимосвязанная вертикаль, иконические лендмарки, sightlines,

> каждая построена вокруг одной механики.

> `Arena.tsx` рендерил карту из массива-описания (kit-of-parts), а не из руками расставленной
> спагетти-геометрии. Движение/сеть/оружие — не трогаем; только «мир».

> Область правок (для реализующего инкремента): `src/data/megamap.ts` (**новый** — данные карты),

## 0. Что уже есть в коде (привязка — реальные факты, не выдумка)

Чтобы спека села на движок:

**Масштаб и координаты (`Arena.tsx`):**
- Войд-пол `#050510` (`isFloor`) на `y=-50` (инк.06 опускает до `y=-120` как дальний фон), грид на `y=-49`, kill-bound `y<-300` (инк.06 `KILL_Y`).
- `CORE_EXCHANGE` — центральный храм, `y=80`, `size=60`, `#f72585`, на нём jump-pad `force=80`, под ним гигантский центр-pad `force=150` на `y=-48`.
- 4 `NODE_*` храма в углах `±200`, `y=20`, `size=40`, `#4361ee`.
- ~90 свечей-платформ (`Candlestick`, `isFloor`) вдоль путей между храмами, emissive + `toneMapped={false}`.
- Kit уже существует как компоненты: `Temple`, `Candlestick`, `Platform`, `Pillar`, `Wall`, `JumpPad` — но расставлены **императивно** (циклы `addCandles`, руками). Мы это **datифицируем**.

**Контракт `userData` (движок читает его — это API карты):**
- `isFloor` / `isWall` — grounded-проба игрока (down-raycast, `Player.tsx:170-190`) и цель для граппла.
- `isJumpPad` + `jumpForce` — прыжковая площадка (задаёт `newY = jumpForce`, `Player.tsx:222`).
- `isEnemy` — актор (граппл латчит и врагов).
- `breakable` + `blockId` + `hp` — **later-хук воксель-разрушения** (инк.02 §3.3): хитскан уже детектит `isWall/isFloor`, добавить `damageBlock`.
- `isWagon`/`isCab`/`wagonIndex` — вагоны поезда (инк.07); несут `isFloor` → по крышам бегается штатно.

**Что умеет движение (карта обязана это ОБСЛУЖИВАТЬ) — `movement.ts` + `Player.tsx`:**
| Механика | Число | Что даёт карте |
|---|---|---|
| ground max speed | `26` | базовый темп CQC |
| bhop hard cap | `95` | по длинным лентам разгон до безумия |
| jump velocity | `16` | обычный прыжок ≈ **4.3 юнита** высоты (`v²/2g`, g=30) |
| double-jump (`airJumps:1`) | ещё `16` | дотянуть разрыв, +короткий второй подъём |
| **jump-pad force** | `60…150` | **главный вертикальный лифт**: `force 80 → ~106 юн` высоты, `150 → ~375 юн`. Пады перебрасывают между ЯРУСАМИ. |
| **jetpack** | `jetMaxUp 13`, fuel 100 / drain 45 | ~**2.2 c** тяги ≈ **+28 юн** подъёма/зависание; репозиция и «доводка» прыжка |
| **grappling hook** | range `140`, pull `65` | латч на любой `isWall/isFloor/isJumpPad/isEnemy` в радиусе **140**; рил + мах, релиз сохраняет импульс → **свинг** |

> **Проектный инвариант дистанций:** любой «разрыв, который задуман под граппл» — **≤140 юнитов** до якоря. Любой «прыжок, задуманный под пад» — высоту берём из `jumpForce` (см. таблицу). Любой «дотянуть» — ≤5 юнитов (обычный прыжок) или ≤8 (даблджамп). Это математика, не вкусовщина.

**Рендер/перф (`Game.tsx`, `PostFX.tsx`):** `shadows={false}`, `dpr=[1,1.5]`, `antialias:false`+SMAA,
`fog [voidDeep, 150, 650]`, свет = `ambient 0.18` + один `directional 0.6`; ВЕСЬ объём —
через **emissive + Bloom** (`intensity 1.1, threshold 0.15`). Значит любой неон карты = материал
с `toneMapped={false}`, иначе Bloom его не подхватит.

**Палитра (`theme.ts`) — залочена, переиспользуем:** мир — ХОЛОДНЫЙ (`void/gridCell/gridSect/bull
#00f5d4/bear #f72585/node #4361ee/accentViolet/accentIndigo/uiCyan/dataEmerald/bloomWhite`); актёры —
ТЁПЛЫЙ набор (`enemyAmber/alertRed/actorWhite`), мир их **не использует большими поверхностями**.
Это и есть правило читаемости в психоделии (см. §1).

## 1. СТОЛПЫ ДИЗАЙНА КАРТЫ

1. **Читаемость сквозь психоделию (cold-world / warm-actors — свято).**
   Вся геометрия карты — в холодной гамме. Ярусы кодируются **цветом-палитрой, не только высотой**:
   `pits`=`node #4361ee`, `mezz`=`bull/bear` свечи, `spire`=`bear #f72585`+`accentViolet`,
   `sky`=`uiCyan` рельс. Игрок по цвету под ногами и на горизонте всегда знает, на каком он ярусе.
   Тёплые частоты не трогаем — иначе далёкая геометрия начнёт «спорить» с врагами за глаз.
   Ключевые тропы подсвечены `bull #00f5d4` кантом (безопасный путь), опасные грани — `bear #f72585`.

2. **Вертикаль с НАМЕРЕНИЕМ, а не «этажерка».**
   Каждый ярус имеет свою боевую грамматику (см. §4). Между ярусами — **явные, читаемые
   маршруты** (pad-лифт / граппл-гонтлет / рельс-оверпасс / рампа), а не «просто прыгай выше».
   Высоты выбраны так, что один pad = ровно один ярус вверх (математика §0).

3. **Movement-tech-first: каждое пространство награждает bhop/jetpack/граппл.**
   Нет ни одного «тупого коридора». Длинные ленты — под разгон bhop. Разрывы — под граппл-свинг
   или даблджамп. Вертикальные шахты — под pad+jetpack-доводку. Если участок нельзя пройти
   «стильно» хотя бы одним техом — он спроектирован неправильно.

4. **Лендмарки для навигации (Elden-Ring-правило «я вижу, куда пойду»).**
   Один доминантный силуэт — **CORE SPIRE** в центре (аналог Эрдтри): виден с любого яруса,
   светится, тянет взгляд. Плюс по одному вторичному лендмарку на зону (§3), читаемому силуэтом
   и цветом издалека. Пульс-ринг из инк.06 A3.4 бьёт из-под Spire — маяк центра.

5. **Геометрия перестрелки: cover + фланги + sightlines + высотное преимущество — в КАЖДОЙ зоне.**
   Правило «нет падений-как-единственной-смерти»: любая высотная позиция имеет (а) укрытие от
   верхнего яруса, (б) хотя бы 2 пути отхода, (в) контр-высоту, откуда её простреливают. Хай-граунд
   даёт **темп-преимущество, а не безнаказанность**.

6. **Всё бесплатно по draw-call'ам (60 fps web).**
   Карта — data-driven kit-of-parts, повторяющиеся пропсы (свечи, шпалы, тикер-столбы, коробки-cover)
   идут в **InstancedMesh** (см. §6). Бюджет статической геометрии карты: **≤ ~40 draw-calls** сверх
   уже существующих космос-оболочек.

## 2. МАКРО-РАСКЛАДКА

Карта сохраняет масштаб текущей арены (footprint ~`±240`, лендмарки на `±200`, CORE в центре),
но перестроена из симметричной «4 угла + центр» в **взаимосвязанную вертикальную мегаструктуру**
из 7 зон на 5 высотных ярусах, сшитую и горизонтально, и вертикально.

### 2.1 Высотные ЯРУСЫ (band-модель)

| Band | `y`-диапазон | Роль | Цвет-код | Смерть? |
|---|---|---|---|---|
| **`sky`** — Sky Rails / Ledger | `+100 … +170` | рельс-оверпасс, поезд, хай-траверс, снайп сверху | `uiCyan` | падение = сквозь всё |
| **`spire`** — Core Spire | `+70 … +120` | центральный King-of-Hill, вертикальный столб | `bear`+`accentViolet` | падение опасно |
| **`mezz`** — Order-Book Mezzanine | `+20 … +70` | свеча-скайлайн, платформинг, мосты | `bull`/`bear` свечи | падение → нижний ярус |
| **`pits`** — Trading Pits / Liquidity | `-10 … +20` | плотный CQC, укрытия, фланги | `node #4361ee` | «дно» боя |
| **`abyss`** — The Abyss | `-120 … -50` | визуальная бездна, kill-floor | `void`/`indigo` | `y<-300` = смерть |

> **Правило анти-«falling-death»:** боевые ярусы (`pits/mezz/spire/sky`) НЕ разделены голой пропастью.
> Между `pits` и `mezz` — уступы/рампы/свечи с шагом ≤5 юнитов; сорвался с `mezz` — падаешь на `pits`
> (потеря позиции), не в abyss. В abyss улетаешь только с внешнего периметра или сбитый специально
> (пад-мисфайр, поезд, нокбек). Тогда inc06-бездна ловит красиво (~3 c падения → respawn).

### 2.4 Критический путь + фланг-петли

- **Критический путь (вертикальный «позвоночник»):** `LIQUIDITY (pit, y0)` → центр-pad `(0,-48) f150`
  выстреливает на **CORE SPIRE top (y~120)** → с вершины прыжок-пад `force 80` или граппл на
  **SKY RAILS**. Это самый быстрый маршрут «со дна на небо» — ось King-of-Hill.
- **Горизонтальное кольцо (mezz-петля):** свеча-мосты соединяют `ORDER BOOK ↔ CORE ↔ BULL/BEAR
  RAMPART ↔ VOLATILITY ↔ DARK POOL` по кругу на `y≈40`. Это «улица среднего яруса» — основной
  фраг-трафик, всегда есть куда сбежать вбок.
- **Фланг-петли:** каждая пара соседних зон связана **двумя** путями разной высоты (нижний CQC-проход
  по `pits` + верхний свеча-мост по `mezz`), чтобы обход по флангу всегда существовал. Пример:
  `DARK POOL → LIQUIDITY` можно низом (pit-туннель) или верхом (граппл-нубы по стене каньона).
- **Sky-петля:** `SKY RAILS` — замкнутое кольцо (rail r≈260); по нему бежится/едется вокруг всей
  карты поверху, спрыгивая грапплом/джетом в любую зону = ротация хай-граунда.

## 3. ЗОНА-ЗА-ЗОНОЙ (7 зон)

Каждая: тема (нео-финанс) · сигнатурная геометрия перестрелки · вертикаль/траверс-хук ·
разрушаемое · лейаут укрытий · лендмарк · standalone-DM-годность.

### Z1 — LIQUIDITY POOLS (Пулы ликвидности) · band `pits` · origin `(-195,+190)`
- **Тема:** утопленный бассейн-«пул» с концентрическими неон-кольцами дна (как маркет-мейкер depth),
  жидкая `dataEmerald`-«ликвидность» плещется в центре (шейдер-декор, не коллайдер).
- **Геометрия боя:** воронка-арена (`sunken pit`, дно `y-10`, борта `y+10`) — **инвертированный
  хай-граунд**: центр низкий и простреливаемый со всех бортов, борта — укрытие. Классический
  «яма-DM»: заходишь по рампам с 4 сторон, дерёшься в чаше.
- **Траверс-хук:** **rim-jump-pad'ы** (`force 60`) на 4 бортах выкидывают из ямы на `mezz`-мосты →
  «выстрел из пула наверх». Граппл-нубы по внутреннему борту для быстрого выхода.
- **Разрушаемое:** кольца-«депт-бары» на дне (`breakable`, hp 120) — cover, который тает под огнём,
  постепенно раскрывая яму (арена мутирует к концу раунда).
- **Укрытия:** концентрические низкие бортики (`node`) + 6 столбов-«ордеров» по периметру.
- **Лендмарк:** пульсирующий `dataEmerald`-столб света из центра пула (виден снизу как маяк «дна»).
- **Standalone-DM:** отличная 1v1/FFA «яма» — компактная, все видят всех, вертикали через rim-пады.

### Z2 — ORDER BOOK (Биржевой стакан) · band `mezz` · origin `(-190,-190)`
- **Тема:** гигантский **bid/ask-стакан**: две встречные лестницы свеча-полок (зелёные bid снизу,
  красные ask сверху) сходятся к «спреду» посередине.
- **Геометрия боя:** **вертикальная дуэль на ступенях** — стек полок `y15→70`, узкие `mezz`-шельфы,
  бой «кто выше по стакану». Sightline вдоль лестницы длинная (снайп), но каждая полка даёт укрытие
  за телом свечи → перебежки полка-в-полку.
- **Траверс-хук:** **обрушаемый свеча-мост** (collapsing candlestick bridge) через «спред»: сегменты
  моста `breakable` (hp 80), под огнём проваливаются → путь исчезает под ногами (It-Takes-Two-момент
  «беги, пока не рухнуло»). Даблджамп + граппл спасают, если сегмент ушёл.
- **Разрушаемое:** мост-сегменты + верхние ask-полки (hp 150) — сбивая их, лишаешь врага хай-граунда.
- **Укрытия:** тела свечей (широкие) — вертикальное укрытие; wick'и (тонкие) — визуальный шум, не cover.
- **Лендмарк:** наклонная башня-стакан, красный верх / зелёный низ, читается силуэтом издалека
  (какой ярус «в тренде» — видно по тому, где горит ярче).
- **Standalone-DM:** вертикальный дуэльный «колодец», сильно про хай-граунд и обрушение.

### Z3 — CORE SPIRE / CENTRAL EXCHANGE (Ядро-Биржа) · band `spire` · origin `(0,0)`
- **Тема:** доминантный центральный шпиль — «сердце биржи», `bear #f72585` + `accentViolet` грани,
  вращающийся неон-тикер-кольцо вокруг вершины. **Главный лендмарк карты** (Эрдтри-аналог).
- **Геометрия боя:** **King-of-the-Hill вертикальный столб**. База `y40` (широкая платформа-«флор»
  инк. `CORE_EXCHANGE`), сужается к вершине `y120` (тесная KotH-площадка). Круговые sightlines 360°
  во все зоны — стоящий на вершине контролит карту, НО открыт со всех рельс/рампартов (контр-высота).
- **Траверс-хук:** **центр-pad `(0,-48) force 150`** — из abyss/pit выстреливает **прямо на вершину**
  (`~375` высоты подброса, доводка jetpack'ом). Плюс верхний pad `force 80` на площадке → на SKY RAILS.
  Спиральные свеча-уступы обвивают шпиль для «пешего» восхождения без пада.
- **Разрушаемое:** декоративные тикер-кольца (`breakable`, косметика); несущая площадка — **НЕ
  breakable** (нельзя удалить главный лендмарк/KotH-цель, инк.02 §3.3 «never make temple floors
  breakable»).
- **Укрытия:** 4 угловых пилона на базе (инк. `Pillar`) + центральный алтарь-блок как cover от снайпа
  с рампартов; на вершине — один низкий парапет (укрытие от рельс-снайпа, но не круговое → надо крутиться).
- **Лендмарк:** сам Spire + пульс-ринг из-под него (инк.06). Видно отовсюду = «я вижу центр».
- **Standalone-DM:** чистый вертикальный KotH — все лезут наверх разными техами, топ дерётся круговой.

### Z4 — DARK POOL (Тёмный пул) · band `pits` (интерьер) · origin `(-200,+40)` (в стене каньона запад)
- **Тема:** закрытый **дарк-пул** — приватная площадка вне «публичных» sightlines (Cyberpunk-интерьер):
  крытый зал, низкая видимость, `accentIndigo` мрак + редкие `uiCyan`-полосы-«скрытые ордера».
- **Геометрия боя:** **интерьер-CQC с углами** — колонны, короткие линии, засады. Контраст к
  открытым ярусам: тут дробовик (wpn 2) и мили (инк.09) — король. 2 этажа внутри (антресоль `y12`
  с проёмами вниз).
- **Траверс-хук:** **grapple gauntlet** — потолочные `isFloor`-балки и стеновые нубы (все ≤140):
  свинг от балки к балке через зал, вход/выход через верхний люк грапплом. «Ниндзя-через-серверную».
- **Разрушаемое:** тонкие перегородки-«файрволы» (hp 80) — простреливаются насквозь, меняя линии;
  можно проделать новый проход (динамическая топология CQC).
- **Укрытия:** плотная сетка колонн (не breakable) + низкие серверные стойки (breakable cover).
- **Лендмарк:** снаружи — тёмный монолит-куб с одной `uiCyan`-щелью-входом в стене каньона.
- **Standalone-DM:** камерная close-quarters-«коробка», отдельный вайб от всей остальной карты.

### Z5 — BULL & BEAR RAMPARTS (Валы Быка и Медведя) · band `pits→mezz` · origin `(+195,-185)` и `(+195,+190)`
- **Тема:** два зеркальных форта-редута — `bull #00f5d4` (NE) и `bear #f72585` (SE), «команды рынка».
  Идеальны как **база-под-команду** (CTF/Domination later) и как sightline-хребет.
- **Геометрия боя:** **длинные снайп-лейны + фланги**. Между двумя рампартами — прямой открытый
  «trend line» коридор (`z`-ось восток) для дальнего боя/рейла (wpn 4). Каждый форт: приподнятый
  вал `y20` (хай-граунд на лейн) + крытые боковые проходы (фланг в обход лейна). Стена-парапет с
  **бойницами-гэпами** (инк. `Wall` с зазорами) — стреляй, прячься.
- **Траверс-хук:** **rail-overpass** — SKY RAILS проходит прямо над рампартами; граппл с вала на
  рельс (≤140) → заскочил на поезд/оверпасс, объехал карту, спрыгнул врагу в тыл. Rampart-roof-pad
  (`force 100`) на крыше → на mezz-мост к CORE.
- **Разрушаемое:** парапет-секции (hp 150) — сбил укрытие снайпера; внешние подпорки (hp 200).
- **Укрытия:** зубчатый парапет (cover-ритм для дуэли на лейне) + внутренние коробки-«позиции».
- **Лендмарк:** два цветных форта на восточном горизонте — мгновенная ориентация «где bull/где bear».
- **Standalone-DM:** пара фортов + лейн = готовая симметричная 2-base-арена (лучшая под TDM/CTF).

### Z6 — VOLATILITY GAUNTLET (Гонтлет волатильности) · band `mezz→sky` · origin `(+200,+40)` (восток)
- **Тема:** **вертикальный маршрут-механика** (It-Takes-Two set-piece): шахта «волатильности» между
  средним ярусом и небом, где свеча-платформы дёргаются вверх-вниз (кинематик, детерминированно от
  world-time — как рельс инк.06, без сети) — «свечи скачут, как VIX».
- **Геометрия боя:** **траверс под давлением** — не арена для стоячего боя, а **connective gauntlet**:
  свинг-якоря + пляшущие платформы, поднимающие с `mezz(y40)` на `sky(y120+)`. Бой = «догнать/сбить
  на маршруте», вертикальный chase. Немного укрытий = высокий риск/темп.
- **Траверс-хук (сигнатура зоны):** **grapple-swing + jetpack-climb гонтлет**. Серия граппл-нубов по
  спирали вверх (шаг ≤120, запас под 140), между ними — jetpack-дожиг (`+28`) через мёртвые зоны без
  якорей. Чистое прохождение = маятник-граппл → релиз-флинг → джет-доводка → следующий нуб. Наверху —
  выход на SKY RAILS.
- **Разрушаемое:** страховочные под-платформы (hp 100) — есть, но если сбиты, промах = падение на mezz
  (не в abyss — правило §2.1).
- **Укрытия:** минимум (2-3 «передышка»-выступа) — зона про движение, не про camp.
- **Лендмарк:** пульсирующая вертикальная неон-шахта на востоке, платформы бегут вверх как тикер.
- **Standalone-DM:** как арена слабее (мало cover) — но как **movement-challenge / race-режим** (later)
  или «нижний-против-верхнего» дуэль — отлично.

### Z7 — SKY RAILS / THE LEDGER (Небесные рельсы / Гроссбух) · band `sky` · origin `ring r≈260`
- **Тема:** высшее кольцо — **гроссбух-оверпасс**, где по рельсу инк.06/07 гоняет crazy-train.
  Над всей картой, `uiCyan` неон-лента, петли/нырки. «Верх мира данных».
- **Геометрия боя:** **хай-граунд-ротация + rail-jumping**. Не сплошная арена, а **сеть узких
  оверпассов + станций-площадок** (`ledger platforms`) вдоль рельса на `y100..170`. Снайп вниз на все
  зоны (макс sightline), НО полностью открыт небу и простреливается с CORE SPIRE (контр-высота).
  Поезд проносится → тайминг «запрыгни/увернись» (инк.07 §4 снос).
- **Траверс-хук:** **поезд как движущийся траверс** (инк.07): догнал bhop'ом → бежишь по крышам →
  спрыгнул грапплом в нужную зону. Плюс rail-jump: с оверпасса граппл-флинг на дальнюю станцию.
- **Разрушаемое:** ничего несущего (рельс детерминирован, инк.06 — не трогаем); только декор-арки-тикеры.
- **Укрытия:** редкие «ledger»-стелы на станциях (cover от снайпа снизу) — мало, high-risk-high-reward.
- **Лендмарк:** сам светящийся рельс-ринг + поезд = виден из любой точки как венец карты.
- **Standalone-DM:** «крыши»-режим — все на оверпассах + поезд как хазард. Экстремальный, для скилловых.

## 4. ВЕРТИКАЛЬНЫЙ + ГОРИЗОНТАЛЬНЫЙ БОЙ (явные ярусы и переходы)

### 4.1 На каких высотах дерутся (и чем ярус отличается)
| Ярус | `y` | Боевая грамматика | Доминантное оружие |
|---|---|---|---|
| `sky` | 100-170 | снайп-сверху, rail-jump, поезд-хазард, всё открыто | рейл (wpn4), плазма (wpn3) |
| `spire` | 70-120 | круговой KotH, контроль центра, 360° осознанность | авто (wpn1), рейл |
| `mezz` | 20-70 | платформинг-перестрелка, мосты, укрытие за свечами | авто, плазма |
| `pits` | -10-20 | плотный CQC, углы, фланги, обрушаемый cover | дробовик (wpn2), мили (инк.09) |

### 4.2 Как техи репозиционируют МЕЖДУ ярусами (карта это гарантирует)
- **Вверх на 1 ярус:** любой зональный jump-pad (`force 60-100`) = ровно +1 band. Всегда есть в каждой зоне.
- **Вверх на 2-3 яруса разом:** центр-pad `force 150` (pit→spire); rampart→mezz; gauntlet-спираль (mezz→sky).
- **Вниз контролируемо:** спрыгнул на нижний ярус (не в abyss) → потеря позиции, не жизни (§2.1). Jetpack
  гасит падение (hover), граппл-нуб внизу ловит и превращает падение в свинг вбок.
- **Горизонтально в пределах яруса:** свеча-мосты (mezz), рампы/туннели (pits), оверпассы (sky). bhop
  разгоняет по прямым лентам до 95 → длинные мосты берутся одним махом.
- **Диагонально (ярус + сторона):** граппл (≤140) — главный «пере-зонный» тех: с вала на рельс, со шпиля
  в пул, с оверпасса в дарк-пул через люк.

### 4.3 Sightline / cover правила (анти-«falling-death», §1.5)
- **Каждая хай-позиция контрится сверху ИЛИ сбоку.** Spire-топ ← рельс+рампарты; рельс ← Spire; rampart-вал
  ← противоположный rampart + Spire. Нет «безнаказанного бога наверху».
- **Каждая хай-позиция имеет укрытие + 2 отхода.** Парапеты/парапет-гэпы/пилоны дают spot-cover;
  всегда есть pad-вниз + мост-вбок как эскейпы.
- **Длинные sightlines разбиты cover-ритмом.** Trend-line между рампартами — не голая труба: зубчатый
  парапет + 3-4 отдельно стоящих блока дают перебежку (snipe-дуэль с укрытиями, не голый прострел).
- **Вертикальные разрывы — не «слепые».** Прежде чем прыгать вниз, видно, куда: нижний ярус читается
  сквозь проёмы (Elden-Ring «я вижу, куда приземлюсь»), не прыжок в туман.

## 5. РАЗРУШАЕМОСТЬ + ПЛАТФОРМИНГ

### 5.1 Что breakable, что стабильно (ties to инк.02 §3.3)
| Стабильно (несущее — НИКОГДА не breakable) | Breakable (cover/мосты — `breakable+hp`, воксель-берст) |
|---|---|
| CORE SPIRE база/площадка (KotH-цель, лендмарк) | LIQUIDITY depth-кольца (hp 120) |
| Все зональные «флоры», по которым идёт критический путь | ORDER BOOK мост-сегменты (hp 80) + ask-полки (hp 150) |
| Rampart несущие валы (band-пол) | DARK POOL перегородки-файрволы (hp 80) + серверные стойки |
| Rail/оверпасс (детерминирован инк.06 — не трогаем) | RAMPART парапет-секции (hp 150), подпорки (hp 200) |
| Jump-pad'ы (лифты — сломать = сломать навигацию) | VOLATILITY страховочные под-платформы (hp 100) |
| Спиральные восхождения на Spire (пеший маршрут) | Все чисто-декоративные тикер-кольца/арки (косметика) |

> **Правило:** breakable — только **cover и опциональные мосты**, никогда — единственный путь или лендмарк.
> Разрушение МУТИРУЕТ арену (раскрывает ямы, убирает укрытия, роняет мосты), но не может запереть игрока
> или удалить навигационный маяк. Breakable-платформы держат высокий hp (100-200), чтобы уходить только под
> сосредоточенным огнём/поездом, а не случайно.

### 5.2 Платформинг-маршруты + скилл-прыжки
- **Пеший (без техов):** спираль-уступы на Spire, лестница-полки ORDER BOOK, рампы в LIQUIDITY — всё
  проходимо обычным прыжком (шаги ≤4 юнита). Каждая зона достижима «ногами» для новичка.
- **Скилл-прыжки (техи):** мосты-разрывы под граппл (≤140), gauntlet-спираль (свинг+джет), rail-jump
  между станциями, «шорткат» центр-pad pit→spire. Награда — темп/фланг, не эксклюзивный доступ.
- **Bhop-ленты:** длинные прямые (trend-line, mezz-кольцо, оверпассы) — под разгон до 95 и dash-прыжки
  через несколько сегментов сразу.

### 5.3 Хазарды
- **Void kill-floor:** только внешний периметр + провалы в abyss; `y<-300` (инк.06). Быстрого «мгновенного»
  дна нет — падаешь сквозь красивую бездну (~3 c), потом respawn.
- **Crazy-train (инк.07):** движущийся хазард на `sky`; сносит с уроном 60 + нокбек + шейк. Тайминг-угроза
  для тех, кто на рельсе/оверпассе; можно оседлать (фича).
- **Jump-pad мисфайр:** пад `force 150` без доводки может перебросить через цель в abyss — рассчитанный риск.
- **Collapsing bridges:** ORDER BOOK мост под огнём проваливается → падение на mezz (не смерть, но потеря
  позиции + надо реагировать грапплом/джетом).
- **Volatility платформы:** дёргаются — таймингованный платформинг, промах = падение на нижний ярус.

## 6. ТЕХ/ПЕРФ ПЛАН (60 fps web)

### 6.1 Инстансинг (главный рычаг draw-call'ов)
Повторяющиеся пропсы одного меша+материала → **один `InstancedMesh` на группу** (`instanceGroup` в данных, §7):
| Группа | Прим. кол-во | Draw-calls |
|---|---|---|
| Свечи-платформы (все зоны) | ~120 | **1** (InstancedMesh, цвет через `instanceColor`) |
| Cover-коробки/depth-бары/серверные стойки | ~80 | **1** |
| Пилоны/колонны | ~60 | **1** |
| Парапет-секции (рампарты) | ~40 | **1** |
| Тикер-столбы/декор-арки/wick'и | ~200 | **1** (косметика, `frustumCulled`) |
| Jump-pad'ы | ~14 | **1** |
| Grapple-нубы (маленькие emissive) | ~40 | **1** |

Остальное (уникальные лендмарки: Spire, 2 рампарта, DARK POOL монолит) — по 2-4 draw-call'а каждый.
**Итого статическая геометрия карты ≈ 25-40 draw-calls** (сверх космос-оболочек инк.06 ≈ +6-10).

> **Коллайдеры для InstancedMesh:** Rapier не берёт коллайдер с `<instancedMesh>` автоматически. Паттерн:
> InstancedMesh рисует (1 draw-call), а коллизия — отдельные лёгкие `<CuboidCollider>`-«сенсоры» без меша
> (или один `RigidBody` с массивом `CuboidCollider` по позициям группы). `userData` (`isFloor`/`isWall`/
> `breakable`) вешаем на коллайдеры (их читает down-raycast/хитскан). Down-raycast игрока идёт по
> `scene.children` — коллайдеры-меши в сцене есть, InstancedMesh-инстансы для raycast'а тоже валидны, но
> дешевле держать явные box-коллайдеры на «стоячих» поверхностях, а чисто-декор (wick/арки) — без коллайдера.

### 6.2 Kit-of-parts модульность (data-driven, не спагетти)
Карта = массив данных (§7) + библиотека prefab-компонентов (`src/components/kit/`). `Arena.tsx` — тонкий
рендерер: читает `MEGAMAP`, группирует по `instanceGroup`, батчит инстансы, спавнит уникальные лендмарки.
Итерация карты = правка массива, **без переписывания `Arena.tsx`**.

### 6.3 LOD / туман для дальнего города
- **Band-туман:** оставить `fog [voidDeep, 150, 650]`, поднять far до ~780 (инк.06 A4) — дальние зоны/рельс
  тают, не обрубаются. Совпадение `fog.color === дальняя shell.color` → «края мира» не видно.
- **LOD:** уникальные лендмарки (Spire, рампарты) — 2 уровня меша (near: пилоны+тикеры; far: силуэт-бокс),
  переключение по расстоянию до камеры (drei `<Detailed>`). Инстанс-группы косметики (тикеры/wick) —
  `frustumCulled` + дистанс-cull через `mesh.count` (не рисуем то, что за far-туманом).
- **Свеча-скайлайн горизонта (инк.06 A3.5):** дальний «бесконечный город-график» — отдельный InstancedMesh
  с чанк-тайлингом, НЕ часть боевой карты (не коллайдится) — чистый бэкдроп за 1 draw-call.

### 6.4 Draw-call бюджет + читаемость под Bloom
- **Бюджет кадра:** статическая карта ≤40 + космос ≤10 + акторы/дебри (инстансы инк.02) + поезд (6) +
  UI. Цель < ~120 draw-calls всего на web — комфортно для 60 fps при `dpr≤1.5`, shadows off.
- **Bloom-читаемость:** мир emissive-холодный, `toneMapped={false}` только на неоне-которому-СВЕТИТЬСЯ
  (канты троп, лендмарки, пады, рельс). Большие поверхности-полы — matt (низкий emissiveIntensity), иначе
  Bloom «зальёт» всё и ярусы сольются. Тёплый набор не трогаем → враги/трассеры всегда «выпрыгивают» из
  холодного мира (правило §1.1). Ключевые тропы — `bull`-кант (safe), опасные грани — `bear`-кант.

### 6.5 Сеть (инк.05): статическая геометрия детерминирована — НЕ синкается
Вся карта — **чистая функция от данных** (`MEGAMAP` + сплайн-seed инк.06), одинаковая на всех клиентах.
По проводу геометрия НЕ летит (как рельс/дебри). Синкаются только акторы (инк.05) и `breakable`-состояние
блоков — **как событие** (`block_destroyed{blockId}`), не как геометрия: сервер авторитетен по hp
(хитскан → `damageBlock` → при hp≤0 broadcast `block_destroyed`), каждый клиент локально проигрывает
воксель-берст (инк.02 §5, косметика). Volatility/collapsing-платформы, что движутся — кинематик от
общего world-time (детерминизм, как поезд), их позиции тоже не синкаются.

## 7. DATA-DRIVEN BUILD (формат описания карты)

Карта авторится как данные + kit реюзабельных prefab'ов. `Arena.tsx` рендерит массив.

### 7.1 Дескриптор (`src/data/megamap.ts`)
```ts
import { PALETTE } from '../theme';
type Vec3 = [number, number, number];

// прим-типы kit-of-parts (каждый = один prefab-компонент в src/components/kit/)
type PrefabKind =
  | 'floor' | 'platform' | 'ramp' | 'wall' | 'pillar'
  | 'candleShelf' | 'bridge' | 'coverBox'
  | 'jumpPad' | 'grappleNub'
  | 'spire' | 'rampart' | 'darkPoolShell' | 'ledgerStation'  // уникальные лендмарки
  | 'kineticPlatform';                                        // volatility/collapsing (кинематик)

interface Prop {
  kind: PrefabKind;
  pos: Vec3;                       // мировые координаты (та же сетка, что Arena сейчас)
  size?: Vec3;                     // half-extents или габарит (по kind)
  rot?: Vec3;                      // Euler, рад (для банка/наклона)
  color?: keyof typeof PALETTE;    // из залоченной палитры (default по band)
  emissive?: number;               // intensity под Bloom (0 = matt пол; 0.5+ = неон)
  // геймплей-флаги → прокидываются в userData коллайдера (движок их читает):
  solid?: 'floor' | 'wall' | 'none';   // → userData.isFloor / isWall / (без коллайдера)
  jumpForce?: number;                   // → userData.isJumpPad + jumpForce
  breakable?: boolean; hp?: number;     // → userData.breakable/blockId/hp (инк.02 later)
  // перф:
  instanceGroup?: string;               // одинаковый string → один InstancedMesh
  // кинетика (kineticPlatform): детерминир. движение от world-time (не синкается)
  motion?: { axis: Vec3; amp: number; period: number; phase: number };
}

interface Zone {
  id: string;                      // 'Z1_LIQUIDITY' ...
  name: string;
  band: 'abyss' | 'pits' | 'mezz' | 'spire' | 'sky';
  origin: Vec3;
  props: Prop[];
  spawns: Vec3[];                  // DM/командные точки спавна этой зоны
}

export const MEGAMAP: Zone[] = [ /* Z1..Z7 */ ];
```

### 7.3 Рендерер (`Arena.tsx` — тонкий, из данных)
```tsx
// псевдо: группируем инстансы, спавним уникальные
const groups = groupBy(MEGAMAP.flatMap(z => z.props.map(p => ({...p, zoneId:z.id}))),
                       p => p.instanceGroup ?? `unique:${p.kind}:${p.zoneId}`);
return <group>
  {/* инстанс-группы: один InstancedMesh на group, коллайдеры отдельно */}
  {Object.entries(groups).filter(([k]) => !k.startsWith('unique:')).map(([g, props]) =>
    <InstancedKit key={g} kind={props[0].kind} props={props} />)}
  {/* уникальные лендмарки: Spire/Rampart/DarkPool/Ledger — свои компоненты */}
  {uniqueProps.map(p => <KitPrefab key={p.id} {...p} />)}
</group>;
```

## 8. MVP vs LATER

### 8.1 MVP — ПЕРВАЯ зона, которую строим (плотная, вертикальная, играбельная 1v1/coop)
**Строим Z3 CORE SPIRE + Z1 LIQUIDITY POOLS как связку** (вертикальный срез «дно→шпиль→небо»):
почему именно это — даёт ВСЮ вертикальную грамматику карты в минимальном объёме и отлично тестируется
вдвоём с другом:
1. **Data-driven каркас:** `src/data/megamap.ts` + переписанный `Arena.tsx`-рендерер + вынести
   существующий kit в `src/components/kit/`. (Инфраструктура, на которой встанут остальные зоны.)
2. **Z3 CORE SPIRE:** шпиль `y40→120`, центр-pad `force 150` (pit→топ), топ-pad `force 80` (топ→sky),
   спираль-уступы, KotH-площадка, пилоны-cover. Главный лендмарк + вертикальный KotH-бой сразу.
3. **Z1 LIQUIDITY POOLS:** утопленная яма `y-10`, 4 rim-пада (`force 60`) на mezz, depth-кольца-cover
   (breakable, hp 120), граппл-нубы. Нижний CQC-ярус + «выстрел наверх».
4. **Связка:** свеча-мосты Z1→Spire-база (`mezz`, bhop-лента) + центр-pad как шорткат. Играбельно:
   один дерётся в яме, другой лезет на шпиль, оба через пады/граппл меняют ярус.
5. **Читаемость:** band-цвета (`node` низ / `bear`+`violet` шпиль), `bull`-канты троп, пульс-ринг центра.
   Проверка на владельце: «вижу центр отовсюду / понимаю, где какой ярус / каждый разрыв беру техом».

**Definition of done (MVP):** двое заходят, дерутся на 3 ярусах (pit / spire-база / spire-топ),
поднимаются падами+грапплом+джетом, ломают cover в яме, никто не умирает «просто от падения»,
60 fps держится, карта читается в Bloom.

### 8.2 LATER (волнами, после подтверждения MVP)
- **Z2 ORDER BOOK** — collapsing свеча-мост + вертикальный стек-дуэль.
- **Z5 BULL/BEAR RAMPARTS** — снайп-лейн + 2 форта (открывает TDM/CTF/Domination).
- **Z4 DARK POOL** — интерьер-CQC + grapple gauntlet (контраст-вайб).
- **Z6 VOLATILITY GAUNTLET** — свинг+джет вертикальный маршрут (+ race-режим later).
- **Z7 SKY RAILS / LEDGER** — оверпассы-станции + интеграция crazy-train (инк.07) как хазард/траверс.
- **Разрушаемость арены** (инк.02 §3.3): включить `breakable` hp-хук + сеть-событие `block_destroyed`.
- **Kinetic-платформы** (volatility/collapsing) — кинематик от world-time.
- **LOD + дальний свеча-город** (инк.06 A3.5) на горизонте за картой.
- **Тонкий тюнинг** высот/дистанций/hp/спавнов на плейтесте с владельцем.

## 9. Human feel-checklist (чем принимаем карту)
- [ ] С любого яруса **виден CORE SPIRE** — «я вижу центр/куда идти» (Elden-Ring-читаемость).
- [ ] По цвету под ногами и на горизонте всегда **понятно, на каком я ярусе** (band-цвета работают в Bloom).
- [ ] Каждый разрыв/подъём берётся **техом** (pad/граппл/джет/даблджамп) — нет «тупых» проходов.
- [ ] Один pad = один ярус вверх ощущается точным; центр-pad выстреливает **со дна на шпиль**.
- [ ] Хай-граунд даёт **темп, а не безнаказанность** — сверху меня всегда есть чем контрить.
- [ ] Сорвался с моста/полки — падаю на **нижний ярус (потеря позиции)**, не в мгновенную смерть.
- [ ] Улетел в abyss — падаю **сквозь красивую бездну ~3 c**, потом respawn (инк.06).
- [ ] Ломаю cover (depth-кольца/парапет/мост) — арена **мутирует**, но я не заперт и лендмарк на месте.
- [ ] Длинные ленты **разгоняют bhop** до безумия; длинные sightlines разбиты укрытиями (не голый прострел).
- [ ] Каждая зона играется и **как отдельный DM**, и как часть одного связного мира.
- [ ] **60 fps** держится (инстансинг, туман, ≤~40 draw-calls карты); карта читается под Bloom, не «залита».
- [ ] Двое клиентов видят **идентичную** карту (детерминизм данных, ноль синка геометрии).
