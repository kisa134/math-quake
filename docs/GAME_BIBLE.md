# MATH QUAKE — БИБЛИЯ ИГРЫ
Единый источник истины: лор, системы, петли, арт, ганфил, законы. Читается в начале каждой сессии.
Никогда не придумываем заново — дополняем ЗДЕСЬ. Прод: https://kisa134.github.io/math-quake/ (репо kisa134/math-quake, авто-деплой push→Pages).

## ЛОР (одним вдохом)
Ты — трейдер, провалившийся ВНУТРЬ рынка в момент мега-ликвидации. Рынок — живой бог: **чёрная дыра-пончик**, всепоглощающая, с радужным глитч-нимбом. **Свечи — души позиций**: 180 штук орбитируют вокруг бога тремя поясами (ритейл-яма / смарт-мани / холдеры вечности), киты ведут стаи, скользящие средние — три светящихся нерва. Каждые **75 секунд** мир проживает полный цикл: НАКОПЛЕНИЕ → ПАМП → ЭЙФОРИЯ → РАСПРОДАЖА → **КАПИТУЛЯЦИЯ** (мир краснеет, дыра в тахикардии жрёт душу каждые 8с) → ТИШИНА. **Белые вокс-чуваки — аватары ликвидированных**: орда идёт вечно, мутируя (берсерки, голдбои, гиганты, ПОЖИРАТЕЛЬ, который ест своих и растёт). **Драконы — маркетмейкеры**: четыре зверя, апекс MARKET MAKER кружит вокруг самого бога; оседлай — и станешь одним из них, с радужной пено-пушкой изо рта. **Деньги — единственная правда**: платят за урон, победы раундов, тотемы; на них покупается сила. Ликвидность бессмертна — умирают только трейдеры (проглоченные свечи возрождаются в гало).

## ПЕТЛИ (ядро дофамина)
1. **Бой**: орда → урон=$2/hp → закуп (P) → жирнее ствол → жирнее орда. CS-раунды: BUY 8с → WAVE 9+3n (кап 30) → победа $1000+150n.
2. **Вертикаль**: крюк-Спайдермен (цепляется ЗА ВСЁ, свинг, буст на отпускании) + джетпак + магнит-ботинки → город на километр → драконы → бог-режим.
3. **Свечи**: стреляй — воксели выгрызаются; <25% — падает и бьётся; литургия сама роняет души в пончик (зрелище) — [будущее: коллапс роняет money-орб].
4. **Стройка (B)**: Fortnite×Valheim детали, снап 2u/90°, статик/физика — арена под себя.
5. **Дофамин-лут**: сферы с трупов (22%): RAGE ×1.6 огонь / SURGE ×1.35 ход / MIDAS ×2$.

## АРТ-ДИРЕКТИВА V5 «Монохром живого рынка»
Выставочный минимализм, модный: почти монохромный **кость-белый мир на тёплом чёрном**, сильные силуэты, минимум цветового шума. **ОДИН акцент-цвет на весь мир, которым дирижирует рынок** (game/accent.ts, из conductor):
- НАКОПЛЕНИЕ #c8b273 приглушённое золото · ПАМП #2fbf71 изумруд · ЭЙФОРИЯ #ffe8b0 белое золото · РАСПРОДАЖА #ff7b00 оранж · **КАПИТУЛЯЦИЯ #ff2d55 кримзон (мир краснеет)** · ТИШИНА #8fa3ad пепел.
- **Кровь — ВСЕГДА кримзон на белых телах** (Superhot-контраст, главный стиль-ход). Души-свечи остаются бык/медведь (контент, не декор).
- Башни: 2 тона графита; стрипы города/MA/пады/HUD = accent. HUD: тонкая типографика, ноль декоративных рамок, var(--accent).
- Пост: сатурация умеренная, виньетка тонкая, Bloom остаётся (глоу = язык мира).

## ГАНФИЛ-СПЕКА «прям как в CS»
- Первый выстрел ВСЕГДА в прицел; tap-fire = снайперская дисциплина; спрей = фиксированный паттерн (учится), сброс 260мс; recovery — ствол доводится вниз после отпускания.
- Viewmodel: ниже-правее-ближе, ствол вдоль взгляда; удар выстрела = кик назад-вверх + FOV-панч + 3-слойный звук (клик-удар-хвост, питч ±8%).
- Прицел: маленький статичный крест, gap дышит спреем и бегом, цвет=accent. Хедшотов нет (пока) — тело едино.
- Рэгдолл: смерть рядом = разлёт 6 частей настоящей физикой (пул 3×6 тел, 2.5с) → растворение в вокс-дебрис.

## ЗАКОНЫ ПЕРФА (нерушимы)
1. Каждый per-frame raycast — с far-клампом; чисто визуальное — `raycast=noop`.
2. Повторяемое — InstancedMesh; материалы — общие, не per-instance.
3. Физика ≤150 тел; орды/свечи/драконы — аналитика без тел.
4. Хореография мира — чистая f(seed,t), ноль сети (оба клиента видят одно).
5. Сетевое — host-авторитет + инбокс-паттерн (socket не импортирует компоненты).
6. Деньги/лут — client-local (честность не цель, дофамин цель).
7. Owner — глаза (мой браузер headless): верификация tsc/build/console, вкус — плейтест.

## НАРРАТИВНЫЕ БИТЫ (очередь на будущее)
- **Боссы эпох**: в КАПИТУЛЯЦИЮ раз в N циклов приходит «Медведь-Архонт» (гигантский вокс-медведь). ПАМП — «Бык-Мессия».

- **Свечи-лут**: коллапс роняет money-орб (визуал $).
